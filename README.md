# 私域落地页 · 发布说明

单文件静态页（`index.html`），无任何外部依赖，微信内置浏览器、Threads 内置浏览器、普通浏览器都能打开。部署到任意静态托管即可。

## 发布前必须核对的 6 件事

| # | 事项 | 位置 | 说明 |
|---|------|------|------|
| 1 | **微信号** | `index.html` 底部 `<script>` 里的 `CONFIG.wechatId` | 目前填的是 `Sjjjjyyyyjszdd`（来自你腾讯投递表里的记录）。如果加微用的是另一个业务号，改这一处即可，页面上所有展示和复制按钮会同步更新 |
| 2 | **微信二维码** | 同目录放一张 `wechat-qr.jpg` | 微信「我 → 二维码名片」截图后裁成正方形，**600×600 以上**、别过度压缩（长按识别需要清晰度）。不放图会显示占位框，放了自动替换 |
| 3 | **头像（可选）** | 同目录放一张 `avatar.jpg` | 放了会自动替换左上角的「合」字印章 |
| 4 | **分享卡片预览图** | `index.html` 头部被注释的 `og:image` | 部署后取消注释，填绝对地址（如 `https://你的域名/og.jpg`，建议 1200×630）。Threads 分享链接时的卡片就靠它 |
| 5 | **占位价格** | 各服务卡片里的 `.price` 行（搜 `class="price"`） | 目前是合理占位数：咨询 ¥299/次、产业服务 ¥3,000 起、教育 ¥699 起、活动免费–¥99、合香珠 ¥88 起、手串 ¥158 起、八字 ¥288、塔罗 ¥168。**上线前全部改成你的真实报价**，改完顺手看一眼 FAQ 第一条的措辞是否还成立 |
| 6 | **文案核对** | 各服务卡片 | 「60 分钟」「当天就能排」「七天内追问」等承诺，按你的真实节奏改；价格不公开、加微发价格表是当前策略 |
| 7 | **真机自测** | 手机上走一遍 | 微信内打开：长按二维码能识别、复制按钮有提示；Threads 内打开：能正常加载 |

## 两条流量链接（区分来源）

页面支持 `?from=` 参数，会自动把「备注示例」换成对应来源，方便你识别流量从哪来：

- **Threads 简介挂**：`https://你的域名/?from=threads`
- **朋友圈发**：`https://你的域名/?from=moments`
- 其他可选值：`xhs`（小红书）、`friend`（朋友推荐）；不带参数则显示默认文案

## 部署方式（任选其一，都免费）

1. **Cloudflare Pages（推荐）**：零备案顾虑、国内访问可用、自带 HTTPS。dash.cloudflare.com → Pages → 上传本文件夹即可，绑定自定义域名更好。
2. **GitHub Pages**：新建仓库 → 上传 `index.html`（和二维码图）→ Settings 里开启 Pages。缺点是国内访问偶发不稳。
3. **Vercel**：`vercel` 命令行或网页拖拽上传，同样简单。

部署完成后，先用手机微信和 Threads 各打开一次再正式投放。

## 备注体系（和你的私域承接对齐）

页面引导用户备注「**来源 ＋ 来意**」：

- 来意三选一：`AI`（咨询/教育/活动）／`香`（合香珠、手串，会触发你计划里的「体质自测」钩子）／`问`（八字、塔罗）
- 加上来源（Threads / 朋友圈），你在微信里一眼就知道流量质量和跟进话术

## 结构速查

- 改 FAQ：搜 `<details>`
- 改配色：`:root` 里的 CSS 变量（朱砂 `--cinnabar`、纸色 `--paper`）
